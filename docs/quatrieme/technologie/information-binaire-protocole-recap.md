# Information binaire et protocole - Récap express

[Fiche complète](information-binaire-protocole-fiche.md){ .md-button } [Quiz](information-binaire-protocole-quiz.md){ .md-button } [Cours détaillé](information-binaire-protocole.md){ .md-button }

## L'essentiel

1. Un **bit** vaut 0 ou 1.
2. Sur 4 bits, les positions valent **8, 4, 2 et 1**.
3. $1011_2=8+2+1=11$.
4. Quatre bits permettent de coder 16 valeurs, de 0 à 15.
5. Une table de correspondance transforme une valeur en caractère ou en commande.
6. Un protocole est un ensemble de règles partagées pour communiquer.
7. Une donnée est un code; l'information est le sens qu'on lui attribue.

## Méthode express

**Découper → convertir en décimal → consulter la table → assembler → contrôler.**

## Piège à éviter

Lire $1010_2$ comme « mille dix » : en binaire, il vaut $8+2=10$.
