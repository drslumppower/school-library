# Racines carrées - Récap express

[Fiche complète](racines-carrees-fiche.md){ .md-button } [Quiz](racines-carrees-quiz.md){ .md-button } [Cours détaillé](racines-carrees.md){ .md-button }

## L'essentiel en 8 lignes

1. $\sqrt{a}$ est le nombre positif ou nul dont le carré vaut $a$.
2. Exemple : $\sqrt{49}=7$ car $7^2=49$.
3. $(\sqrt{a})^2=a$ et $\sqrt{a}\times\sqrt{a}=a$.
4. Les carrés parfaits de $0^2$ à $15^2$ permettent de calculer rapidement.
5. $\sqrt{13}$ est une valeur exacte.
6. $\sqrt{13}\approx3{,}61$ est une valeur approchée au centième.
7. Comme $9<13<16$, alors $3<\sqrt{13}<4$.
8. Une racine carrée permet de retrouver une longueur à partir de son carré.

## Carrés à connaître

## Le piège principal

$\sqrt{36}=6$, pas $\pm6$. C'est l'équation $x^2=36$ qui possède les deux solutions $6$ et $-6$.
