# Géométrie - Fiche de révision

## Coordonnées dans l'espace

$$
(x\,;y\,;z)=\text{horizontal ; profondeur ; hauteur}
$$

Toujours vérifier l'origine, le sens des axes et l'ordre demandé.

## Les trois vues

| Vue | Dimensions visibles |
|---|---|
| face | largeur + hauteur |
| côté | profondeur + hauteur |
| dessus | largeur + profondeur |

Correspondances à contrôler :

- même largeur entre face et dessus ;
- même hauteur entre face et côté ;
- même profondeur entre côté et dessus.

## Volume d'un assemblage

$$
V_{cube}=a^3
$$

Pour plusieurs cubes : calculer chaque volume, multiplier par le nombre de cubes identiques, puis additionner.

## Outils de construction

| Outil | Usage |
|---|---|
| règle graduée | mesurer et tracer un segment |
| compas | reporter une longueur |
| équerre | construire un angle droit |
| rapporteur | mesurer ou construire un angle |

## Constructions types

### Trois côtés connus

Tracer un côté, puis deux arcs dont les rayons sont les deux autres longueurs.

### Triangle rectangle

Tracer un côté, puis une perpendiculaire à l'extrémité où se trouve l'angle droit.

### Triangle isocèle

Le sommet principal se trouve à l'intersection de deux arcs de même rayon centrés aux extrémités de la base.

### Triangle équilatéral

Les deux arcs ont pour rayon la longueur du côté.

## Lire le codage

- mêmes traits sur deux côtés : côtés de même longueur ;
- petit carré : angle droit ;
- mêmes arcs : angles de même mesure.

## Pièges à éviter

- inverser les coordonnées ;
- oublier les cubes cachés ;
- confondre vue de face et perspective ;
- mesurer une figure qui n'est pas en vraie grandeur ;
- conclure d'après l'apparence sans utiliser le codage.
