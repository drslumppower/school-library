## Dates

- Jours et mois avec une majuscule : *Monday, September*.
- Date britannique : *Wednesday, 16th September 2026*.
- Exceptions : **1st, 2nd, 3rd**, puis généralement **-th**.
- Nombres composés : *twenty-first, twenty-second, twenty-third*.

## Description d'image

1. *This document is a photograph.*
2. *There is... / There are...*
3. *In the foreground / in the background...*
4. *She is wearing... / They are playing...*
5. *It must be cold.*

## Deux constructions

- Action en cours : **sujet + am/is/are + verbe-ing**.
- Capacité : **sujet + can/can't + base verbale**.

## L'erreur à ne pas faire

Écrire *She can plays* ou *She can to play*. Il faut écrire **She can play**.
