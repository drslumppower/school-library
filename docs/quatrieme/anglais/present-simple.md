# Le présent simple

## Les pronoms sujets

| Singulier | Pluriel |
|---|---|
| **I** : je | **we** : nous |
| **you** : tu / vous | **you** : vous |
| **he** : il | **they** : ils / elles |
| **she** : elle | |
| **it** : il / elle pour une chose ou un animal | |

Le pronom **I** s'écrit toujours avec une majuscule. Les autres pronoms ne prennent une majuscule qu'en début de phrase.

## Les emplois

Le présent simple sert à parler de ce qui est habituel, régulier ou généralement vrai. On l'emploie pour les routines, les goûts et les vérités générales.

## La forme affirmative

Avec **I, you, we, they**, on utilise la base verbale : *They play football.*

Avec **he, she, it**, le verbe prend généralement **-s** : *She plays football.* Certains verbes prennent **-es**, comme *go → goes* ou *watch → watches*.

## La négation

On emploie l'auxiliaire **do** :

- *I do not (don't) like coffee.*
- *He does not (doesn't) like coffee.*

Le verbe placé après *don't* ou *doesn't* reste toujours à la base verbale.

## Les questions

L'auxiliaire passe devant le sujet :

- *Do you play chess?*
- *Does she play chess?*

On peut répondre brièvement : *Yes, I do*, *No, I don't*, *Yes, she does* ou *No, she doesn't*.

Dans une question, le point d'interrogation se place uniquement à la fin : *Do you like chocolate?*

## Exprimer la fréquence

Les adverbes indiquent à quelle fréquence une action se produit. Ils se placent avant le verbe principal, mais après le verbe *be*.

- *We usually eat at home.*
- *He never drinks coffee.*
- *They are often tired.*
