## L'essentiel en 10 lignes

1. Synthèse **additive** = lumières, primaires **RVB**.
2. rouge + vert = jaune ; vert + bleu = cyan ; bleu + rouge = magenta ; les trois = blanc.
3. Synthèse **soustractive** = matières et filtres, primaires **CMJ**.
4. cyan + jaune = vert ; jaune + magenta = rouge ; magenta + cyan = bleu ; les trois = noir.
5. Complémentaires : rouge-cyan, vert-magenta, bleu-jaune.
6. Un filtre absorbe sa couleur complémentaire et transmet le reste.
7. Un objet ne renvoie que les composantes présentes dans la lumière reçue.
8. Couleur perçue = composantes communes entre l'éclairage et l'objet.
9. Aucune composante commune : l'objet paraît **noir**.
10. La vision est trichromatique : trois types de cônes (bleu, vert, rouge).

## Le réflexe de méthode

**Décomposer la lumière → repérer ce que l'objet diffuse → garder l'intersection → additionner.**

## L'exemple à retenir

Objet cyan (diffuse vert + bleu) sous lumière jaune (rouge + vert) → **vert**.

## L'erreur à ne pas faire

Confondre les primaires **RVB** (lumières) et **CMJ** (matières).
