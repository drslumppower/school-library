# Récap express - TD Attacheur AP25

[Fiche complète](etude-cas-attacheur-ap25-fiche.md){ .md-button } [Quiz](etude-cas-attacheur-ap25-quiz.md){ .md-button } [Approfondir l'étude de cas](etude-cas-attacheur-ap25.md){ .md-button }

## L'essentiel en 10 lignes

1. L'AP25 attache les sarments de vigne au fil de palissage.
2. Utilisateur : le **viticulteur** ; besoin : gagner du temps et réduire la pénibilité.
3. Autonomie : environ **8 000 attaches** par journée.
4. Confort : **1 kg** maximum en main, **2 kg** maximum à la ceinture.
5. Milieu : indice **IP55**, de **$-5\,°\text{C}$ à $40\,°\text{C}$**.
6. Limites d'emploi : sarment $20\ \text{mm}$ et fil $2\ \text{mm}$ maximum.
7. Serrage réglable de **3 à 9 tours** de torsade.
8. Un **seul moteur** entraîne deux sous-mécanismes via des **roues libres**.
9. Sous-mécanisme 1 : entourer, avancer, couper. Sous-mécanisme 2 : torsader.
10. Le **pré-actionneur** distribue l'énergie au moteur.

## Le cycle d'attache

**Gâchette → fermer le crochet → avancer le lien → couper → torsader → ouvrir le crochet → préparer le cycle suivant.**

## Le réflexe de méthode

**Associer chaque composant à une fonction générique avant de conclure.**

## L'erreur à ne pas faire

Classer le lien dans les flux d'énergie : c'est un flux de **matière**.
