# Récap express - Holiday Survey

## L'essentiel en 10 lignes

1. Le prétérit décrit une action **terminée dans le passé**.
2. Verbe régulier : base verbale + **-ed**.
3. **watch → watched**, **cook → cooked**, **visit → visited**.
4. Verbe irrégulier : forme à apprendre.
5. **go → went**, **have → had**, **break → broke**.
6. **read → read**, mais la forme passée se prononce `/red/`.
7. Question : **Did + sujet + base verbale?**
8. Après **did**, écrire **go**, jamais *went*.
9. Préciser avec **where, what, which, who, how old**.
10. Pour rapporter : “I went…” → “She/He went…”.

## Le réflexe de méthode

**Repérer le marqueur du passé → choisir le prétérit → vérifier si le verbe est régulier ou irrégulier.**

## L'exemple à retenir

“Where **did** you **go**?” → “I **went** to Portugal.”

## L'erreur à ne pas faire

Écrire *Where did you went?* : après **did**, le verbe revient à sa base verbale.
