# Holiday Survey

## Goal

The aim of the activity is to interview classmates about their summer holidays and report what they did using the **preterit** (past simple).

1. Form groups of three, four or five.
2. Read the categories together.
3. Ask questions about the summer holidays.
4. Write one classmate's name and some details in each relevant category.
5. Turn the notes into complete sentences in the preterit.

## Holiday activities

| Category | Example sentence |
|---|---|
| go abroad | Léa **went abroad**. |
| watch a TV series or a good movie | Sam **watched a TV series**. |
| have an accident | Alex **had an accident**. |
| cook a new recipe | Charlie **cooked a new recipe**. |
| go to the beach | Lou **went to the beach**. |
| have a birthday | Noa **had a birthday**. |
| read a new book | Camille **read a new book**. |
| practise sports | Robin **practised sports**. |
| visit family members | Sasha **visited family members**. |

## Forming the preterit

### Regular verbs

For most regular verbs, add **-ed** to the base form.

| Base form | Preterit |
|---|---|
| watch | watched |
| cook | cooked |
| visit | visited |
| practise | practised |

!!! note "Spelling"
    *Practised* is the usual British spelling for the verb. American English uses *practiced*.

### Irregular verbs

Irregular verbs do not follow the **-ed** rule and must be learned.

| Base form | Preterit | Example |
|---|---|---|
| go | went | She went abroad. |
| have | had | He had an accident. |
| read | read | She read a book. |
| break | broke | He broke his arm. |

The past form **read** is written like the present form but pronounced `/red/`.

## Asking questions about the past

Use **did + subject + base verb**:

> Question word + did + subject + base verb + complement?

- Where **did** you **go**?
- What **did** you **watch**?
- What **did** you **cook**?
- Which sport **did** you **practise**?
- Who **did** you **visit**?

!!! warning "Common mistake"
    After **did**, use the base form: **Where did you go?**, not *Where did you went?*

For questions with **be**, do not use *did*:

- Where **were** you?
- Who **was** with you?

## Asking for details

| Information needed | Useful question |
|---|---|
| country | Which country did you visit? |
| series or movie | What did you watch? |
| accident | What happened? / What type of accident did you have? |
| recipe | What did you cook? |
| beach | Which beach did you go to? |
| age | How old did you turn? |
| book | Which book did you read? |
| sport | Which sport did you practise? |
| family | Which family members did you visit? |

## Reporting the answers

When reporting, replace **I** with the person's name or **he/she**.

- “I went to Portugal.” → **Maya went to Portugal.**
- “I watched *Wednesday*.” → **Tom watched *Wednesday*.**
- “I visited my grandparents.” → **She visited her grandparents.**

## Remember

- Use the preterit for a completed action in the past.
- Add **-ed** to regular verbs.
- Learn irregular forms such as **go → went** and **have → had**.
- After **did**, keep the verb in its base form.
- Ask a second question to obtain a precise detail.
