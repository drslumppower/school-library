## L'essentiel

1. Le présent simple exprime les habitudes et les vérités générales.
2. Forme affirmative : sujet + base verbale.
3. Avec **he, she, it**, on ajoute généralement **-s** au verbe.
4. Forme négative : **do not / don't** + base verbale.
5. Avec **he, she, it** : **does not / doesn't** + base verbale.
6. Question : **Do/Does + sujet + base verbale?**
7. Réponse courte : **Yes, I do. / No, she doesn't.**
8. Les adverbes de fréquence incluent *always, usually, often, sometimes, never*.
9. Ils se placent généralement avant le verbe lexical.
10. Avec *be*, l'adverbe se place après le verbe.
